## 🚀 Personal Projects

Self-directed, end-to-end projects — problem selection, data, modeling and deployment all my own.

### [🎬 cinema-etl-pipeline](https://github.com/pedro-otero-pago/cinema-etl-pipeline)
Fully automated ETL pipeline that scrapes local cinema showtimes, cleans and transforms the data, and loads it into a relational database. 17 tests and daily runs scheduled with GitHub Actions.<br/>
`Python` `BeautifulSoup` `pandas` `SQL` `GitHub Actions` `pytest`

### [📉 churn-prediction-api](https://github.com/pedro-otero-pago/churn-prediction-api)
Customer churn prediction service: EDA, a compared and justified model choice (GradientBoostingClassifier), served through a FastAPI app with input validation and tests, containerized with Docker.<br/>
`Python` `scikit-learn` `FastAPI` `Docker` `pytest`

### [📚 local-rag-assistant](https://github.com/pedro-otero-pago/local-rag-assistant)
Fully local RAG assistant for document Q&A: PDF chunking, embeddings and generation via Ollama (no external API calls), a deduplicated ChromaDB vector store and a Streamlit chat interface.<br/>
`Python` `Ollama` `ChromaDB` `Streamlit` `pytest`

> 🔜 **Coming next:** an interactive EDA dashboard on Spain's hourly energy demand, generation and weather.
